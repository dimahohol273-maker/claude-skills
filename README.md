# Telegram Gift Bot

Бот для управления и апгрейда подарков в Telegram.

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate  # Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Получите токен бота:
   - Напишите [@BotFather](https://t.me/BotFather)
   - Отправьте `/newbot`
   - Следуйте инструкциям
   - Скопируйте полученный токен

4. Настройте окружение:
```bash
copy .env.example .env
```
   - Откройте `.env` и вставьте токен в `BOT_TOKEN=`

5. Запустите бота:
```bash
python bot.py
```

## Команды бота

- `/start` - Приветствие и главное меню
- `/gifts` - Показать доступные подарки
- `/inventory` - Ваши подарки
- `/upgrade` - Апгрейд подарка
- `/help` - Помощь

## Возможности

- Просмотр доступных подарков
- Управление инвентарем подарков
- Система апгрейда подарков
- Интерактивное меню с кнопками
